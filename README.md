# rocavence/homebrew-tap

```sh
brew install --cask rocavence/tap/wunder
```

[Wunder](https://wunder.rocavence.com): a cabinet of curiosities for your Mac.

```sh
brew install --cask rocavence/tap/flione
```

[Flione](https://flione.rocavence.com): a music player for Jellyfin and YouTube Music on the Mac.

```sh
brew install --cask rocavence/tap/gamely
```

[Gamely](https://gamely.rocavence.com): pauses Hot Corners while macOS Game Mode is on.

```sh
brew install --cask rocavence/tap/configgy
```

[Configgy](https://configgy.rocavence.com): backs up and restores your Mac's app settings to your own cloud folder, never your logins or keys.
